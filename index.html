계산식과 적용 조건

호스트 단독 목표 = 도펀트 실제 속도 × (100 − 증착 목표 vol%) / 증착 목표 vol%
합산 감지 목표 = 호스트 단독 목표 + 도펀트의 호스트 채널 감지 기여

증착 계산에 사용하는 vol%는 소수점 둘째 자리로 반올림합니다. 예: 4 wt% → 4.724409… vol% → 4.72 vol%.
호스트 채널에서 호스트 단독 감지 속도가 실제 두께 증가 속도에 대응한다는 조건입니다. 감지 기여는 해당 장비에서 측정한 값을 입력하세요. 모든 속도에 동일한 단위를 적용합니다.

시간 계산 기준

예상 시간 = 목표 두께 ÷ (호스트 실제 두께 증가 속도 + 도펀트 실제 두께 증가 속도). 위 증착 계산과 같이 호스트 단독 감지 목표가 실제 두께 증가 속도에 대응한다고 가정합니다.

합산 감지 목표에는 도펀트의 호스트 채널 감지 기여가 포함되므로 시간 계산의 분모로 사용하지 않습니다. 속도가 일정하고 두 성분 부피가 가산되는 조건의 예상치이며, 속도 안정화·셔터 지연 등 준비 시간은 제외합니다.

농도 변환 원리

두 성분의 질량을 w, 분자량을 M, 실제 밀도를 ρ라 하면:
wt% = 100 × wᴅ / (wʜ + wᴅ)
mol% = 100 × (wᴅ/Mᴅ) / (wʜ/Mʜ + wᴅ/Mᴅ)
vol% = 100 × (wᴅ/ρᴅ) / (wʜ/ρʜ + wᴅ/ρᴅ)

mol% 입력은 각 성분의 몰 비율 × 분자량으로, vol% 입력은 부피 비율 × 밀도로 질량을 구한 후 변환합니다. 혼합물의 부피는 각 성분 부피의 합으로 계산합니다.
